# Changelog

## 1.0.2

- Every release now also becomes a GitHub Release, with ready-made zip files attached (`solomonRM6`, `solomonRM7` and the demo pages) and these notes as its description.
- The website link in the README now points to the new home of the project page: https://www.redmine-solomon.onlinemegjelenes.com

## 1.0.1

- Added a Redmine 7 build (`solomonRM7`) next to the Redmine 6 build (`solomonRM6`). Both are generated from one source and look the same.
- Added demo pages with Redmine 6 and Redmine 7 markup (`demo/rm6/`, `demo/rm7/`).

## 1.0.0

- First public release: a purple, glass-style theme for Redmine 6.
- Card-style issue lists, status and priority pills, count badges in block titles.
- Restyled issue details, calendar, sidebar, flash messages and login page.
- 10 color variants with a gear-icon picker on the right edge.
- English and Hungarian UI texts (follows the Redmine language).
